# Docker Application

This repo hosts configuration files for creating single or multi container docker applications. These are fairly simple configurations and not to be used for production environments and the intention is that they need to be self contained.

| Folder               | Description                                                                                                                                                     |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| data-analytics-stack | This is the data analytics stack which includes a middleware, database and a BI tool.  **Apache NiFi**, **PostgreSQL**, **Metabase BI Tool** and **ClickHouse** |
